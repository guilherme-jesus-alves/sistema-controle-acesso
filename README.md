# Sistema de Controle de Acesso

Sistema desktop desenvolvido em C# com Windows Forms e SQL Server para gerenciamento e controle de acesso em portaria.

## 📋 Sobre o projeto

O Sistema de Controle de Acesso foi desenvolvido com o objetivo de auxiliar no gerenciamento de uma portaria, permitindo o cadastro e controle de diferentes tipos de pessoas e registros relacionados ao acesso.

O projeto foi desenvolvido durante a formação acadêmica/profissional em Tecnologia da Informação.

## 💻 Tecnologias utilizadas

- C#
- Windows Forms
- .NET Framework
- SQL Server
- ADO.NET
- Programação Orientada a Objetos

## 🔐 Funcionalidades

- Login e autenticação de usuários
- Cadastro de usuários
- Cadastro de associados
- Cadastro de funcionários
- Cadastro de visitantes
- Controle de acesso
- Registro de entregas
- Consultas de informações
- Gerenciamento de registros da portaria

## 🗄️ Banco de dados

O sistema utiliza o SQL Server para armazenamento e gerenciamento dos dados.

A aplicação utiliza ADO.NET para realizar a comunicação entre o sistema e o banco de dados.

## 🖥️ Aplicação

O projeto é uma aplicação desktop desenvolvida para ambiente Windows utilizando Windows Forms.

Para executar o sistema, é necessário configurar o ambiente de desenvolvimento, o .NET Framework e o SQL Server.
